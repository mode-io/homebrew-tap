# Mode IO Homebrew Tap

Homebrew formulas for Mode IO tools.

## Install

```bash
brew tap mode-io/tap
brew install <formula>
```

## Available formulas

Formulas are added here as public releases become available.

## MOP

modeio all-in-one process monitor with AI security review (Linux).

```bash
brew install mode-io/tap/mop
mop
```

[Source and installation options](https://github.com/mode-io/mop)
